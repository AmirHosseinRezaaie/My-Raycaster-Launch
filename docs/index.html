Key Features

High-Performance DDA Algorithm

Utilizes the Digital Differential Analysis (DDA) algorithm for ultra-fast ray-grid intersection calculations. Each frame casts hundreds of rays with microsecond precision, ensuring smooth 60 FPS gameplay even on modest hardware.

Runs at Blazing 60 FPS

Optimized rendering pipeline with frame-rate independent movement ensures buttery-smooth gameplay. Advanced distance-based culling and efficient memory management deliver consistent performance across all platforms.

Real-Time Map Editor

Toggle between 3D gameplay and 2D map editing with a single keypress! Create custom levels on-the-fly, save them to disk, and share with friends. Features intuitive mouse-based wall placement and removal with instant visual feedback.
