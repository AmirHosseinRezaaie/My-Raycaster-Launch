# 🎮 RayCaster Pro - Retro 3D Engine

> A high-performance raycasting engine built from scratch in pure C

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![C Standard](https://img.shields.io/badge/C-C99-blue.svg)](https://en.wikipedia.org/wiki/C99)

## 🌟 Overview

RayCaster Pro is a modern implementation of the classic raycasting technique used in early 3D games like Wolfenstein 3D.

🔗 [Visit Official Website](https://AmirHosseinRezaaie.github.io/My-Raycaster-Launch/)

---

## ✨ Features

- ⚡ High-Performance DDA Algorithm
- 🗺️  Real-Time Map Editor
- 🎨 Distance-Based Shading
- 💾 Save/Load System

---

## 🛠️ Tech Stack

| Component | Technology |
|-----------|-----------|
| Language | Pure C (C99) |
| Graphics | Raylib |
| Build | Make |
| Version Control | Git |

---

## 📦 Installation

### Ubuntu/Debian:
bash
sudo apt update
sudo apt install build-essential git libraylib-dev
### Build & Run:
bash
git clone https://github.com/AmirHosseinRezaaie/My-Raycaster-Launch.git
cd My-Raycaster-Launch
make
./raycaster
